# YTDow 2.3.0

> **Требуется чистая установка Android.** Версии 2.2.0–2.2.3 были подписаны
> временным Android Debug certificate. Версия 2.3.0 начинает новую защищённую
> production signing identity и не может быть установлена поверх 2.2.x.

Перед установкой:

1. Убедитесь, что нужные загрузки находятся в публичной папке
   `Downloads/YTDow`.
2. Удалите YTDow 2.2.x.
3. Установите APK 2.3.0 из этого релиза.

Файлы в `Downloads/YTDow` сохраняются после удаления приложения. Внутренняя
история загрузок и настройки 2.2.x будут сброшены. Начиная с 2.3.0 последующие
версии смогут обновляться обычным способом при сохранении production-ключа.

## Основные изменения

- Надёжная отмена и повтор загрузок, история попыток и безопасная работа с
  MediaStore.
- Усиленная проверка WebView, внешних URL и APK-обновлений.
- SBOM, строгая проверка зависимостей и production-only release pipeline.
- Обновлённый desktop-клиент с историей, отменой и проверкой URL.

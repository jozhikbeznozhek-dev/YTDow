# Политика приватности YTDow

Дата вступления в силу: 9 августа 2026 года.

YTDow не содержит аналитики, рекламы, аккаунтов или собственного облачного
сервера. История URL, история загрузок и настройки хранятся локально на
устройстве. Android исключает эти данные из облачной резервной копии и
переноса между устройствами.

Для выполнения функции приложения введенный URL и сетевые метаданные
передаются непосредственно сайту-источнику и его CDN через `yt-dlp`. При
ручной проверке обновления приложение обращается к GitHub API и скачивает APK
только с доверенных доменов GitHub. GitHub и сайты-источники обрабатывают
соединения по собственным политикам приватности.

Загруженные файлы сохраняются в `Downloads/YTDow` (Android) или в выбранную
локальную папку (desktop). Удаление из библиотеки затрагивает только файлы,
которые YTDow может подтвердить как принадлежащие своей папке или записи
MediaStore.

YTDow не может определить, разрешено ли скачивание конкретного материала.
Пользователь обязан соблюдать авторские права, условия сайта и применимое
законодательство.

Вопросы о приватности и сообщения о проблемах принимаются через GitHub Issues:
https://github.com/jozhikbeznozhek-dev/YTDow/issues
